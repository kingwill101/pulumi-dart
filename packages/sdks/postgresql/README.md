# pulumi_postgresql

Generated Pulumi provider SDK for Dart.

## Installation

~~~sh
dart pub add pulumi_postgresql
~~~

## Usage

~~~dart
import 'package:pulumi_postgresql/pulumi_postgresql.dart' as provider;
~~~

## Alternative: Use directly from GitHub

~~~yaml
dependencies:
  pulumi_postgresql:
    git:
      url: https://github.com/<owner>/<repo>.git
      path: packages/postgresql
      ref: main
~~~
