# pulumi_aws

Generated Pulumi provider SDK for Dart.

## Installation

~~~sh
dart pub add pulumi_aws
~~~

## Usage

~~~dart
import 'package:pulumi_aws/pulumi_aws.dart' as provider;
~~~

## Alternative: Use directly from GitHub

~~~yaml
dependencies:
  pulumi_aws:
    git:
      url: https://github.com/<owner>/<repo>.git
      path: packages/aws
      ref: main
~~~

See the example/ directory for a runnable sample.
