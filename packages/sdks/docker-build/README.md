# pulumi_docker_build

Generated Pulumi provider SDK for Dart.

## Installation

~~~sh
dart pub add pulumi_docker_build
~~~

## Usage

~~~dart
import 'package:pulumi_docker_build/pulumi_docker_build.dart' as provider;
~~~

## Alternative: Use directly from GitHub

~~~yaml
dependencies:
  pulumi_docker_build:
    git:
      url: https://github.com/<owner>/<repo>.git
      path: packages/docker-build
      ref: main
~~~

See the example/ directory for a runnable sample.

_This file is preserved across SDK regeneration done via task generate:<provider>._
