# pulumi_newrelic

Generated Pulumi provider SDK for Dart.

## Installation

~~~sh
dart pub add pulumi_newrelic
~~~

## Usage

~~~dart
import 'package:pulumi_newrelic/pulumi_newrelic.dart' as provider;
~~~

## Alternative: Use directly from GitHub

~~~yaml
dependencies:
  pulumi_newrelic:
    git:
      url: https://github.com/<owner>/<repo>.git
      path: packages/newrelic
      ref: main
~~~

See the example/ directory for a runnable sample.
