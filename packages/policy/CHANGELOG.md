# Changelog

## 1.0.0

- Initial manual Dart package scaffold for `pulumi_policy`.
- Ported core public API types/classes for policy definitions.
- Added typed validation/remediation helper functions.
- Added docs, example, and basic unit tests.
- Implemented the analyzer gRPC runtime for Dart-authored policy packs.
- Added upstream-compatible decoding for unknown preview values, secrets,
  assets, and archives, including secret-preserving remediation mutations.
